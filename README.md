# 🤖 数字员工系统（Digital Employee Platform）

一套开箱即用、**真实能干活的** AI 数字员工管理系统：创建数字员工、派发任务、定时值班、在线沟通。数字员工不仅能调用**国产大模型**生成内容（DeepSeek / 通义千问 / Kimi / 智谱 GLM 等），更能**真实执行动作**——读取文件、整理数据、抓取网页、推送通知，产出真实的成果文件。

## ✨ 功能一览

| 模块 | 说明 |
| ---- | ---- |
| 👥 员工管理 | 招聘/编辑/调岗数字员工，配置人设指令、绑定技能、在岗/暂休/离线排班 |
| 📋 任务中心 | 派单 → 技能匹配 → 执行 → 成果归档；优先级、进度、重试、取消 |
| 📦 工作台 | 成果文件库：查看/预览/下载/删除数字员工的真实产出（报告、CSV、笔记） |
| 💬 在线沟通 | 与数字员工实时对话，任务产出自动同步为员工汇报 |
| ⏰ 定时调度 | cron 驱动 7×24 自动值班（如每日晨报、每 10 分钟巡检），触发即自动执行 |
| ⚙️ 系统设置 | 模型配置 + 通知渠道（钉钉/企微/飞书）+ 技能库 + 运行日志 |
| 🎯 仪表盘 | 团队态势、任务成功率、员工效能榜 |

## 🛠️ 技能库（v3：真实干活 + 多模态）

**🖼️ 多模态技能（图片 / 文档真实处理）**

| 技能 | 能力 | 产出 |
| ---- | ---- | ---- |
| 🖼️ 图像分析 | 分析上传的图片（内容识别 / OCR / 图像理解），视觉模型执行 | 分析报告（无 Key 时登记图片元数据） |
| 📑 文档解析 | 真实提取 PDF / Word(docx) / Excel(xlsx) / TXT 文本内容 | 解析笔记（文本提取无需大模型） |

**🔧 工具类技能（真实执行，无需大模型）**

| 技能 | 能力 | 产出 |
| ---- | ---- | ---- |
| 📂 文件整理 | 读取 `server/data/inputs/` 真实素材文件并盘点 | CSV 文件清单 |

| 🔔 通知推送 | 任务结果推送到钉钉/企微/飞书 Webhook，主动向真人汇报 | 送达回执（未配置时存档） |

> 所有任务产出自动落盘为成果文件（`server/data/outputs/`），可在「工作台」下载——**干完活就有东西交**。

## 🔗 任务节点编排（每节点可选不同模型）

派发任务支持两种模式：

- **⚡ 快速任务**：单技能单模型，即派即干
- **🔗 节点编排**：把任务拆成多个节点按顺序执行，**每个节点可独立配置技能 + 模型**

```
例：合同解析流水线
 节点1 解析文档    [doc]      模型 qwen-plus（多模态）
 节点2 整理要点    [data]     模型 跟随全局
 节点3 生成简报    [report]   模型 deepseek-chat
```

- 节点输入支持 `{prev}` 占位符，自动注入上一节点输出（上下文传递）
- 各节点产出文件独立归档（`节点N-` 前缀），任务输出为节点结果汇总
- 多模态模型参考：`qwen-vl-max`（通义视觉）、`glm-4v-plus`（智谱视觉）、`qwen-plus`（通用）
- 对话也支持直接发送图片（多模态对话）

## 🖼️ 多模态素材

- 任务表单/对话均可上传图片与文档（PNG/JPG/WebP/PDF/DOCX/XLSX/TXT/CSV/MD/JSON，≤15MB）
- 上传文件存于 `server/data/attachments/`，派发「图像分析」「文档解析」任务即可加工
- 无 API Key 时：图像分析登记图片真实元数据，文档解析照常提取真实文本（确定性能力不依赖大模型）

## 🚀 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动服务（首次自动初始化种子：4 名数字员工 + 示例任务 + 定时调度）
npm start

# 打开控制台
#   http://localhost:8787
```

开发模式（前后端热更新）：

```bash
npm run dev:server   # 后端 :8787
npm run dev:web      # 前端 :5173（代理 /api）
```

## 🧠 模型配置（国产模型）

启动后到「系统设置」页配置，或设置环境变量：

| 变量 | 说明 | 默认 |
| ---- | ---- | ---- |
| `LLM_API_KEY` | API Key | 无（未配置时自动进入模拟模式） |
| `LLM_BASE_URL` | OpenAI 兼容端点 | `https://api.deepseek.com` |
| `LLM_MODEL` | 模型名 | `deepseek-chat` |

快捷预设：**DeepSeek** / **通义千问**（DashScope 兼容模式）/ **Kimi** / **智谱 GLM**，也支持任意自定义端点。

> 未配置 Key 时系统自动降级为**模拟模式**：内置规则引擎按技能生成确定性产出（报告框架、数据表格、巡检日志等），保证全流程可演示。配置 Key 后同一套流程即由大模型智能执行。

## 📁 项目结构

```

├── server/                  # 后端（Express + SQLite，零编译依赖）
│   ├── src/

│   │   ├── db.js            # SQLite 数据层（node:sqlite）
│   │   ├── llm.js           # 模型大脑（OpenAI 兼容 + 模拟降级）
│   │   ├── artifacts.js     # 产出物系统（成果文件落盘/清单/下载）
│   │   ├── seed.js          # 种子数据（4 名员工 + 素材样例 + 调度）
│   │   ├── engine/
│   │   │   ├── runner.js    # 任务执行引擎（真实工具执行 + 产出归档）
│   │   │   └── scheduler.js # cron 定时调度器
│   │   ├── skills/          # 技能库（v2：9 项，含真实工具类）
│   │   └── routes/          # REST API 路由
│   └── data/
│       ├── inputs/          # 输入素材区（放真实文件给员工加工）
│       ├── outputs/         # 成果文件库（员工产出，备份即成果）
│       └── digital-employees.db  # SQLite 数据
└── web/                     # 前端（React + Vite，纯手写 CSS）
    └── src/pages/           # 仪表盘/员工/任务/工作台/沟通/调度/设置
```
